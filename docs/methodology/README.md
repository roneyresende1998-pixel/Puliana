# Metodologia Genesis — Portal 1 a 7 + Módulo 11

Esta pasta é onde você cola o conteúdo/resumo de cada portal do curso
Defiverso. Cada arquivo `.md` aqui vira contexto automático pro agente
(veja `backend/app/tools/methodology.py`).

Sugestão de organização:

```
docs/methodology/
├── portal-1.md
├── portal-2.md
├── ...
├── portal-7.md
└── modulo-11.md
```

O nome do arquivo (sem `.md`) vira o título da seção que vai pro prompt do
agente. Nenhum conteúdo do curso está incluído por padrão neste kit —
preencha com suas próprias anotações de aluno.
